# Credits and provenance

This community project builds on M5Stack's documentation and open-source libraries, LVGL and the MCP ecosystem. It is independent of M5Stack and OpenAI.

- [M5Stack documentation](https://docs.m5stack.com/): exact-board specifications and hardware guidance. Device knowledge records retain direct source URLs.
- [M5Burner](https://burner.m5stack.com/): discovery of community firmware and projects. A catalog listing is not permission to copy its code or assets; credit each original author and check the actual license before adapting work.
- [M5Stack LVGL emulator](https://github.com/m5stack/lv_m5_emulator): the initial native display/input approach, MIT.
- [M5GFX](https://github.com/m5stack/M5GFX): graphics/font sources and board support, with its original per-file notices.
- [LVGL](https://github.com/lvgl/lvgl): native framebuffer rendering, MIT and retained component notices.
- MCP SDK, MCP Apps and OpenAI MCP extensions: local tools and fixed host integration. Full bundled license texts are in the plugin's `licenses/` directory.

See [JavaScript dependency notices](plugins/m5stack-preview/THIRD_PARTY_NOTICES.md) and [native/source notices](plugins/m5stack-preview/runtime/THIRD_PARTY_NOTICES.md) for exact versions, provenance and license details. Official product photographs are not bundled; the casing illustrations are CSS.

Original code is licensed under [MIT](LICENSE), copyright 2026 Federico Sarquis. The reusable shake detector came from his HelloCounter experiment and remains an input utility; its provenance is retained. The earlier 8 Ball, mascot and trail applications, alternate viewers and provider experiments are not included. There is one editable Hello World starter for all five profiles.
